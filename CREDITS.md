# Credits

HARROW is a private hobby project. This file is shown in game (main menu
and pause menu, Credits). Every external asset, with its licence, source
URL and exactly which files ship, is logged in [ASSETS.md](ASSETS.md); this
page is the short list of who made what. The CC BY attributions under Audio
are required; CC0 work needs no credit, and we give it anyway.
